# 🌌 Black Hole Simulator — NEBULA X
## ✨ Features

- 🌌 Animated black hole and glowing accretion disk
- 💫 Orbiting particles with neon colors
- 🖱️ Move the black hole with your mouse
- ⚡ Adjust the simulated gravity effect
- 🎮 Pause, resume, and reset the particle field
- 🌠 Futuristic space-themed interface

## 🛠️ Built With

- Python 3
- Pygame

## 📋 Requirements

- Python 3.10 or newer
- pip

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/ngan200612-del/Black-Hole-Simulator.git
```

### 2. Enter the project folder

```bash
cd Black-Hole-Simulator
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run the simulator

```bash
python main.py
```

## 🎮 Controls

| Control | Action |
|---|---|
| Mouse | Move the black hole |
| Up Arrow | Increase gravity effect |
| Down Arrow | Decrease gravity effect |
| Space | Pause / Resume |
| T | Toggle trail mode |
| R | Reset particles |
| Esc | Exit |

## 🔬 About the Simulation

This project demonstrates a stylized 2D black hole effect
using animated particles, glowing rings, and an accretion disk.

It is a visual simulation, not a physically accurate model
of gravitational lensing or general relativity.
